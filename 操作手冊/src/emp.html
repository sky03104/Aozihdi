1登入系統

步驟 1　開啟天鷹保全 APP 網址，等待金色光環啟動動畫。
步驟 2　輸入你的 工號 與 密碼。
步驟 3　可勾選 記住我，下次自動登入。
步驟 4　按「登入」，看到「✅ 登入成功」即進入首頁。
⚠️ 工號不存在或密碼錯誤會有紅色提示。忘記密碼請洽主管或管理員重設。

修改密碼

進入後可於設定處修改密碼，輸入舊密碼與兩次新密碼即可。

2認識首頁

登入後首頁由上而下：

  • 問候與身分：顯示你的姓名、部門、職務。
  • 📢 公告橫幅：點一下可查看全部公告。
  • 四格統計卡片：可用工具數、公告數、常用工具數、今天日期。
  • ⭐ 常用工具快捷：你加入收藏的工具會出現在這裡，一鍵開啟。

把工具加入「常用」

到「工具」頁 → 點工具卡片右上角的 ⭐ → 該工具就會出現在首頁常用快捷。再點一次取消。

底部「工具」頁列出你有權限使用的工具，可用搜尋框找工具。不同職務看到的工具不同。常見工具：

核心工具資料上傳工具上傳班表等 Excel 資料

4常用工具操作教學

📋 事故報告填寫
現場管理
  1. 選擇事故日期與時間（預設為現在）。
  2. 填寫事故地點、選事故類別（一般事故／竊盜／爭執／設備故障／意外受傷／火警…）。
  3. 詳細描述事故經過。
  4. 可上傳現場照片（最多 3 張），點＋上傳。
  5. 按「提交事故報告」，看到綠色成功提示即送出，2 秒後返回主選單。
送出後主管會在後台看到此筆並處理；你不需要做其他動作。
🚨 匿名表揚／反應
緊急應變
  1. 選擇類型：表揚 或 反應（檢舉／反映）。
  2. 填寫對象（被表揚或反映的人員姓名／工號）。
  3. 選事由分類、填事件描述、選發生日期。
  4. 可附圖片（最多 5 張）。
  5. 送出 → 看到「提交成功」。
🔒 前台完全匿名，你的身分不會顯示在報告上。（後台僅供主管辨識防濫用，一般不對外。）
🔒 打烊後 / 🔓 開店前進出快速登錄
核心工具
  1. 於「登錄」頁選擇專櫃／廠商、監工人員、檢查者。
  2. 填進場時間／退場時間。
  3. 送出 → 自動寫入雲端試算表。
  4. 切到「今日」頁可查看當天已登錄紀錄。
大量貼上時系統會自動去重，避免重複登錄。
📅 班表查詢
人事管理
  1. 選本週班表或本月班表，系統自動帶入你自己的工號（不用手動輸入）。
  2. 畫面依日期排列，每天顯示班別代號，早班常見 A（08:00-20:00）／S（08:00-16:00）／H（11:00-22:00）／H2（11:00-23:30）／L（12:00-20:00）／LN（12:00-24:00）／南（南館班）；晚班常見 B（20:00-08:00）／海（22:00-10:00）／N（20:00-24:00）；另有休、排休、事假、病假、補休、見習等非上班代號。
  3. 不同班別代號用不同顏色區分，一眼就能分辨當天是不是上班日。
  4. 也可以直接用 LINE 機器人 輸入「本月班表」「本週班表」「今日班表」「明日班表」查詢，不用開 APP（見《LINE 機器人操作手冊》）。
跨月查詢（例如月底查下個月）暫不支援，請等新月份班表公告後再查。
📝 請假申請
人事管理
  1. 可在 APP 內申請，或用 LINE 機器人 申請（見《LINE 機器人操作手冊》），兩邊送出的申請會匯到同一個地方。
  2. 選擇請假日期與請假原因，確認後送出。
  3. 送出後狀態為待審，等待帶班以上主管審核。
  4. 審核結果（核准／駁回）會透過 LINE 通知你，不用自己回來查看。
📞 緊急聯絡清單
緊急應變
  1. 依單位／分類找到要找的緊急聯絡電話。
  2. 手機號碼開頭的 0 會正確顯示，不會被系統誤判成數字而遺失。
  3. 點電話號碼可直接撥打（手機瀏覽器支援一鍵撥號）。
📋 今/明日哨表
核心工具
  1. 頂部有 ☀️ 今日 / 🌙 明日 兩個切換鈕，點一下即可切換查看。
  2. 畫面依早班（08:00~20:00）、晚班（20:00~08:00）分區，各哨點的姓名／進場時間一目瞭然。
  3. 右上角 ⟳ 可手動重新整理。
🕒 每天 08:00 系統會自動把「明日哨表」內容轉為「今日哨表」；若當天哨表還沒排定，會顯示「尚未更新」提示，不會誤看到舊資料。
🚚 物流車輛統計
核心工具
  1. 於「登記」頁選擇車輛分類：1.9噸／3.5噸／8噸以上。
  2. 用 － / ＋ 輸入幾輛，登記時間自動採「送出當下」。
  3. 有常用組合時，直接點下方快捷登記按鈕一鍵送出，不用重選分類與數量。
  4. 「今日累計」小卡即時顯示當天三分類各自的總數。
  5. 切到「查紀錄」頁可選日期查當天明細，或「查看整月」看每日 × 分類統計。
「設定」頁（管理員限定）可維護快捷登記組合，全員登記頁會同步看到最新快捷按鈕。
☁️ 資料上傳工具
核心工具
  1. 依畫面提示選擇要上傳的檔案（例如班表 Excel、哨表 Excel）。
  2. 系統會自動判讀檔案內的日期，決定要更新的分頁。
  3. 上傳完成會顯示成功訊息；資料會直接同步到雲端試算表，全公司帳號查詢時就會看到最新內容。
⚠️ 此工具會直接覆蓋線上資料，上傳前請確認檔案內容正確，避免誤傳造成資料被覆蓋。
🅿️ 停車場車位數計算
核心工具
  1. 分區輸入B1F、B2F、機車格目前的實際佔位數（現場實際停了幾輛）。
  2. 系統依各區總車位數自動算出剩餘可用車位，即時顯示在畫面上。
  3. 提供給現場人員或引導車輛的同仁參考，不需要自己心算。
🚗 過夜車輛登記
門禁管理
  1. 點「拍攝車牌」，用手機鏡頭對準車牌拍照。
  2. 系統自動用 AI 辨識車牌號碼，3 秒後自動登記；辨識期間可以點車牌文字手動修改。
  3. 若辨識失敗，畫面會提示「辨識失敗，請手動輸入車牌」，直接用鍵盤輸入即可。
  4. 登記完成後可在清單查看今天所有過夜車輛紀錄。
📋 施工單查詢
資料管理
  1. 頂部分頁切換：今天 / 明天 / 已申請 / 歷史，另有「施工單查詢」與「動火申請查詢」兩種類別可切換。
  2. 每張卡片顯示廠商專櫃名稱、施工地點、施工項目、監工、進場／退場時間。
  3. 上方搜尋框可用廠商、地點、監工關鍵字快速篩選當天記錄。
  4. 廠商人員現場報到時，點卡片上的「 報到換證」按鈕完成報到；已報到的卡片會顯示「已報到換證」。
「明天」分頁會同時顯示明日新排的施工單，以及今日通宵（跨夜）尚未退場的記錄，避免漏看夜間仍在場的廠商。
🔄 帶班交接事項
人事管理　·　組長以上

只有組長／副隊長／隊長／主管／管理員才看得到，用於換班時把現場注意事項交接給下一班。

  1. 頂部輸入框填寫要交接的事項內容（如故障設備、待追蹤事件），按「送出」新增，預設狀態為未完成。
  2. 分頁切換：全部 / 未完成 / 進行中 / 已完成。
  3. 每筆事項顯示建立人／時間與最後修改人／時間，方便追查交接紀錄。
  4. 點狀態徽章可切換未完成 → 進行中 → 已完成，或編輯內容、刪除該筆。
接班先看「未完成」「進行中」分頁，處理完記得切回「已完成」，讓交接紀錄保持乾淨，方便下一班接手。

5工號狀態與返回主選單

  • 各工具會自動帶入你的工號，操作都會記錄是誰做的。
  • 工具內按 「返回主選單」 會回到首頁，不需要重新登入（會保留登入狀態）。
  • 要換人或結束，按首頁的「登出帳號」。
