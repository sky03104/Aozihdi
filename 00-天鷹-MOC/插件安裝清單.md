# Obsidian 插件安裝清單

> 開啟 Obsidian → Settings → Community plugins → Turn off Safe mode → Browse

## 必裝（核心功能）

| 插件名稱 | 用途 | 設定要點 |
|----------|------|----------|
| **Obsidian Git** | 自動同步 GitHub | 見下方設定 |
| **Dataview** | 筆記查詢（MOC 儀表板用）| 開啟 JavaScript Queries |
| **Templater** | 智慧模板（自動帶入日期/變數）| Template folder = `_Templates` |
| **Calendar** | 側邊欄月曆，快速開 Daily Note | Daily Note folder = `99-Daily` |

## 建議裝（提升效率）

| 插件名稱 | 用途 |
|----------|------|
| **Tasks** | `- [ ]` 任務追蹤，支援截止日篩選 |
| **Tag Wrangler** | 批次管理標籤 |
| **Outliner** | 更順手的縮排列表操作 |

---

## Obsidian Git 設定步驟

```
Settings → Obsidian Git

✅ Auto pull on startup
✅ Auto commit-and-sync
   Commit interval (minutes): 30
   Commit message: vault: {{date}} auto-backup

✅ Pull updates on startup
```

> ⚠️ 若同時使用 GitHub Desktop 提交 index.html 等程式碼，
> 兩者不衝突——Obsidian Git 只自動 commit Markdown 筆記的變動。
> 程式碼改動仍用 GitHub Desktop 手動 commit + push。

---

## Templater 設定

```
Settings → Templater
Template folder location: _Templates
✅ Trigger Templater on new file creation
```
